## Замечания по чтению кода

- Хранилище работает в памяти: между запусками данные не сохраняются.
- Консольные циклы не завершаются при EOF (закрытом стандартном вводе); выходить следует через пункт 0. Этот сценарий отдельно не запускался.
- Пользовательский порог доброты допускает любое целое число, хотя доброта животного ограничена 1–10.
- Тестовый проект содержит зависимость xunit наряду с MSTest; отдельного xUnit-адаптера нет. Удалять зависимость следует после проверки всех её использований.
